# Facundo Contreras - Blog de Trading

Blog profesional de Facundo Contreras, trader especializado en opciones binarias.

## 🚀 Tecnologías

- **React 19** - Framework UI
- **TypeScript** - Tipado estático
- **Vite** - Build tool y dev server
- **CSS Modules** - Estilos modulares

## 📦 Instalación

```bash
npm install
```

## 🛠️ Scripts

```bash
# Desarrollo
npm run dev

# Build de producción
npm run build

# Preview del build
npm run preview

# Linter
npm run lint
```

## 🎨 Características

- Diseño moderno con colores naranja ardiente y negro
- Sección Hero con presentación
- Videos embebidos de YouTube
- Carruseles de operaciones exitosas
- Sección de comunidad de Telegram
- Grid de videos del canal
- Diseño completamente responsive
